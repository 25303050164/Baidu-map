### 3.2 预算竞争与错误机制

当前源码评分为：

```text
C = 是否同时存在 ≤900 与 >900 的有效观测
N = max(0, 1 - min(|t - 900|) / 120)
R = 中心与四角均值之差的绝对值（满足有效性条件时）
V = 有效样本最大值 - 最小值
U = size/400 × [4C + 2N + 2min(R/120,1) + min(V/300,1)]
candidate = C 或最近阈值距离≤120 或 R>60 或 V>300
```

北部某 400 米格所有有效样本为 1515～2567 秒，仍可得 3 分，高于 100 米格的分数上界 2.25。待验证假设 H1 是：这类动作是否在存在可执行边界动作时先占用预算，影响阈值分类；不称为“远处都不值得采”。

每个决策记录当时样本与有效性、C/N/R/V、尺寸、原始分数、动作类型、需要新增的唯一坐标、缓存和预留状态、剩余预算、当时最优可执行边界替代动作及成本、选取／跳过原因。边界动作必须当时已经存在并且预算能承担，不能借用后续才生成的格子。

请求按首次预留动作归属一次费用，重试继承该动作；共享点对其他格子的支持另建多对多表。分别核对预留、确认发送、未确认发送、完整响应和重试。

按 1～400、401～800 两段报告：
- 全部相关观测有效且核验通过、最小时间 >1020 秒的格子驱动了多少新增请求；
- 其中多少请求发生在存在可执行边界替代动作时；
- 可替换的完整动作成本及只改排序的首次分叉位置。

解释探索为 0 的具体过滤链。源码在细化前探索，候选要求非边界候选且观测全部有效；不能预先断言是预算提前用完。

逐个复核 12 个剩余错点和 7 个恢复点的叶格、实际观测、插值三角形、支持和栅格裁剪，以及新增点的决策来源。灰区分解为新增失效、三角形支持变化、栅格额外屏蔽和未归因部分；分类可能重叠，不能直接相加。

## 5. P2：新独立参考与 800 次配对试点

先冻结候选、当前集成基线、工具、依赖和下述协议，再申请执行新真实预算。只采集新的先导和评价数据；算法进程不能读先导、评价、哨兵或旧参考文件，缓存各自独立。

### 5.1 固定点集

使用 SHA-256 从 `20260911＋阶段名称＋格子ID` 派生子流，锁定 PCG64 和 NumPy 版本，不使用 Python 内置 hash。格子以西南角为起点，稳定整数 ID；每轴在格内 5%～95% 区间均匀取样。种子命名、规范化格式和点文件哈希须写进协议。

1. **先导 128 点**：±1600 米范围划分 8×8 格，每格两个内部随机位置。仅完整端点且偏移 ≤50 米的有效秒数形成先导标签。先导不进入最终主评价。
2. **全域评价 64 点**：同一 8×8 格，每格一个新随机位置，使用独立子流。
3. **边界评价 64 点**：只在同格或四邻格的有效先导异号点之间建立候选边，按稳定点 ID 去重；从中选 16 对，每对取局部坐标线段的 1/8、3/8、5/8、7/8 处四点。异号仅表示相邻标签不同，不假设中间耗时连续或仅有一次越界。

**配对规则：每个先导端点最多参与两条选中边，每条边只选一次。** 旧 24 条变化边实际只有 15 个可达端点，完全不共享端点的最大匹配为 14，说明“16 对完全不共享端点”不适合作为无条件默认。旧证据只用于设计可行性判断，不代替新先导结果。该容量在新请求前固定，不在结果不足后临时放宽。

采用端点容量 2、边容量 1 的二分图最大流检查能否选够 16 对。不足则停止，不自动增加先导、不放宽容量。每步先移除已选边、扣除各端点已用容量，再对每条候选边模拟扣减其容量；只有剩余图仍能完成所需数量时才可选。第一对选最短线段，之后最大化“候选边中点到已选边中点的最小局部米制距离”；平局按线段长度、稳定边 ID。最大流只作为可完成性判断，选边不能依赖它偶然返回的流分解。可用标准库实现，不新增路网依赖。

这些是分散点对，**不是 16 个统计独立邻域**。记录端点使用次数、共享端点连通分组、中点间距、覆盖格和实际路线端点聚集。“跨三个点对组改善”只是空间分布描述，不作为三个独立证据。

转换 BD09LL 并归一化六位后，检查重复、越界、与先导／全域点重合；检查失败即停止，不按已返回结果移动或补点。最终 128 点全部保存、哈希固定后才开始其请求。

### 5.3 稳定性哨兵与顺序

从有效先导中固定八个诊断哨兵：在可达／不可达两类各取距 900 秒最近的两个；其余四个按最远点优先补足，距离平局按稳定点 ID。每个先导点只选一次；缺少所需类别或不足八个则不启动算法。

候选冻结后，算法顺序由独立 order 子流提前抽取并保存，运行后不改。执行序列为：先导 → 最终参考 → 哨兵前批 → 方法 A → 哨兵中批 → 方法 B → 哨兵后批。哨兵数据不进入算法缓存或主评价，不覆盖原参考标签。

前批至少六个有效；之后每相邻两批至少六个同点有效配对。有效配对中至少两个点出现 ≤900／>900 翻转，或配对不足六个，停止尚未执行的方法。若后批才发现异常，整轮比较记证据不足，不自动重测。只出现一个翻转也照常报告其影响；少量哨兵不证明全部参考长期稳定。

专用入口直接运行步行 Provider 和算法，不经过会追加设施查询的业务流程；显式选择 duration 路线指标，不绑定设施 UID。两方法使用相同当前 Provider、RateGate 和 5／10 分钟附加轮廓配置，附加计算耗时单列。实时共享同一个限流器，其他消耗该步行配额的任务停止。

## 6. 指标、验收与停止

### 6.1 统一口径

全域层和边界层分别输出“参考可达／不可达 × 预测可达／不可达／unknown”的 2×3 计数表。

- 误纳率：`FP/(TP+FP)`。
- 漏纳率：参考可达且预测不可达或 unknown 的点数／参考可达数，拆开 known-negative 与 unknown。
- unknown 比例：预测 unknown／有效共同参考。
- 辅助误纳比例：`FP/N_negative`，不替换主误纳率。
- 所有零分母为 null；有效空几何与 null 区分。null／失败按全 unknown 保留评价，同时标明方法失败。
- 报实际确认发送、预算预留、未确认、重试、响应、耗时、质量、停止原因、未知面积及分量／孔洞数。unknown 面积不能直接当成错误面积。

阈值始终为 900 秒，不删除临界点。严重误纳层为参考 >1020 秒，另报 >960 秒、距阈值 ≤15 秒和端点偏移分层；这是研究分层，不改变主标签。

### 6.2 真实筛选结论

只有版本、参考覆盖、稳定性、两方法执行和调用审计均有效，才判断质量筛选：

| 结论 | 条件 |
| --- | --- |
| 候选通过筛选 | 边界 FN 净少至少 3 点；至少 3 个预先固定点对组各净少至少 1 点；边界 FP 不增；全域 FN、FP 均不增；无新增基线没有的 >1020 秒 FP |
| 混合证据 | 边界收益达标，但全域 FN 或 FP 增加，且未触发严重误纳保护 |
| 未通过 | 边界收益不足、边界 FP 增加（即使 FN 改善达标），或出现新增严重误纳／离线漏岛保护失败 |
| 证据不足或运行无效 | 版本、配对、参考覆盖、哨兵、执行或审计条件不满足，或任一方法以 deadline 结束 |

先判运行和证据条件，再判硬保护／边界条件，最后判全域变化，避免分支重叠。deadline 结果保留全部指标，不能据此宣布候选通过；正常 budget 结束或合法提前完成按其余规则评价。

在固定集合中 TP 增加且 FP 不增时，主误纳率本身不会升高，不另设“允许增加 2 个百分点”的窗口。原严重误纳未修复仍作为未解决风险，不能用总错误数下降掩盖。

真实稀疏参考只能判断已观测点，不能验证整片区域没有漏检。整片漏岛门槛只用于结构已知的合成场景。新主集、旧 93 点回归和端点敏感性结果分表，不混成一个成绩。

耗时是独立观察项，不要求更准确的 800 档比历史 400 档更快。保持相同截止，拆分本地开销与网络；单次耗时变化不称为稳定性能优势。真实面积 IoU、边界 P95、现场步行准确率和普遍排名本轮不报告。

未通过或证据不足后停止本轮，不扩大额度、补采、换系数或换候选重试。候选通过也只表示值得进入多社区和重复运行验证，不能自动替换默认产品算法。
