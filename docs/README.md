## 迁移约定

- `architecture/`：跨模块需求、架构和算法设计。
- `api/`：跨模块接口契约和公开 schema。
- `operations/`：启动、联调和部署说明。
- `acceptance/`：可复现的验收记录。
- `references/`：外部资料和原始参考文件。

这些目录暂不承载迁移后的副本；每次迁移必须同步修复相对链接，并完成文档链接检查后再提交。
