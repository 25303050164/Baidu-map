# 文档索引

仓库文档按用途组织，避免把当前说明、设计资料和一次性验收产物混在同一层。

## 当前入口

- [当前状态](../CURRENT_STATE.md)：当前实现、版本和已知限制。
- [架构与需求](architecture/README.md)：产品需求、总体方案和算法设计。
- [地区设施检索与体检报告实施方案](地区设施检索与体检报告实施方案.md)：跨模块功能拆分和接入边界。
- [后端说明](../backend/README.md)：后端接口、运行方式和算法入口。
- [前端说明](../life-circle-demo/README.md)：前端启动、接口契约和演示入口。
- [算法包说明](../life-circle-algorithm/README.md)：可复用 Python 算法包及测试方式。

## 目录约定

- `architecture/`：跨模块需求、架构和算法设计。
- `api/`：跨模块接口契约和公开 schema；模块私有契约仍放在所属模块的 `docs/`。
- `operations/`：启动、联调、部署和故障排查说明。
- `acceptance/`：可复现的验收记录和结论。
- `references/`：外部资料、原始命题和不可执行的参考文件。
- `backend/reports/`、`backend/docs/assets/`：历史验收证据。新增大型截图或原始结果前，应优先考虑外部制品存储或 Git LFS。

## 文档规则

1. 当前有效的结论写入稳定命名的说明文件；日期写在版本记录或验收记录中。
2. 一次性实验输出和截图不作为接口或算法规范的唯一来源。
3. 移动文档后必须同步修复相对链接，并用 `rg` 检查旧路径。
